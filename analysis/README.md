# Climbing Analysis

This directory contains the Python statistical analysis and its data products.
It is separate from the Android application in `app/`.

## Layout

- `model2.py`: send probability, surprisal, session timing, rest, and attempts-to-send analysis
- `model3.py`: performance, load, fatigue, ACWR, and injury analysis
- `model4.py`: predictors of signed performance
- `model4_send.py`: predictors of send surprise
- `model4_fail.py`: predictors of failure surprise
- `average_testing.py`: moving-average workload and injury tests
- `de_model.py`: readiness-state timescale model
- `data/climb_data.csv`: current exported attempt-level input data
- `data/derived/`: tables generated by the analysis scripts
- `data/database/`: current database snapshot used during data exploration
- `data/backups/`: historical exports and application/database snapshots
- `docs/`: definitions of performance and ACWR metrics
- `outputs/plots/`: PNG figures grouped by model
- `outputs/reports/`: final analysis reports
- `outputs/report_working/`: intermediate report-rendering assets
- `scripts/`: report-generation utilities

## Running Models

Run scripts from the repository root:

```bash
python3 analysis/model2.py
python3 analysis/model3.py
python3 analysis/model4.py
python3 analysis/model4_send.py
python3 analysis/model4_fail.py
python3 analysis/average_testing.py
python3 analysis/de_model.py
```

The paths are resolved relative to this directory, so the same scripts also work
when launched from another working directory. Replace `data/climb_data.csv` when
using a newly exported dataset.

Regenerate the model-results PDF with:

```bash
python3 analysis/scripts/make_python_results_summary_pdf.py
```
